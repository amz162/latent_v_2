- Recent swing highs/lows.

- Actual executable-reference price.
- Cost profile.

Do not allow arbitrary hallucinated target/stop numbers.

## Entry reference

For completed daily data:

- Signal after the completed session.
- Next valid session open is the default hypothetical entry reference.

For delayed snapshots:

- Record actual retrieval time.
- Use a defensible first-observable-price rule.
- Label the result `delayed_observation_shadow`.
- Do not backdate an entry into a period before the app received the information.

Never execute a historical signal at the same close used to create it unless a documented execution mechanism genuinely supports it.

## Stop-loss

A long-position stop must be below the entry price.

Use a documented rule based on:

- ATR.
- Verified technical support.
- Confirmed price-pattern invalidation.
- Existing strategy risk policy.

If a defensible stop cannot be determined, return `NO_TRADE`.

## Targets

For a long setup:

- TP1.
- TP2.
- TP3.

Use technically defensible resistance levels or predeclared reward multiples.

Targets must be above entry.

Do not create targets beyond reasonable market evidence without explaining the assumptions.

## Risk/reward calculation

Calculate net reward and net risk using whole-share sizing and V2 trading costs.

The conceptual formula is:

`Risk/Reward = Expected Net Profit at Selected Target / Absolute Expected Net Loss at Stop`

Include:

- Entry cost.
- Exit brokerage.
- PSX fees.
- NCCPL fees.
- CDC fees.
- Applicable taxes.
- Slippage assumptions.
- Position quantity.

The exact calculation must use:

`computeSimTradeCosts` → `computeTradeCostsV2`

Do not subtract costs twice.

If the denominator is zero, negative or unavailable, the ratio is unavailable and the setup is invalid.

Report each target separately where useful:

- `rr_to_tp1`
- `rr_to_tp2`
- `rr_to_tp3`

Do not allow the LLM to write an attractive risk/reward ratio that differs from the deterministic calculation.

## No-trade controls
